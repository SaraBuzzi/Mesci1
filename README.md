# MESCI — Wine Bar Website

A website designed and developed for MESCI, a wine bar in Pioltello, Italy, specializing in wines from independent producers, cocktails, and tapas.

**Live website:** [www.mesci.it](https://www.mesci.it/)

## Overview

MESCI is a real-world web project created to establish an online presence for a local business and make its information and menu easily accessible to customers.

The website combines a distinctive visual identity with a clear content structure, providing information about the venue, its offering, and how to get in touch.

## Features

- **Custom visual identity:** A cohesive design with a tailored color palette, typography, and SVG logo.
- **Responsive layout:** An interface designed to adapt to desktop and mobile screens.
- **Interactive navigation:** Section-based navigation with a dedicated mobile menu.
- **Digital menu:** An interactive menu organized into food and drink categories, allowing visitors to browse the offering without navigating away from the page.
- **Direct menu access:** A dedicated menu section that can be accessed through a direct link, making it easier to share the menu with customers.
- **Business information:** Dedicated sections introducing the venue and providing contact and location information.
- **Web essentials:** Page metadata, favicon assets, and supporting files for browser and mobile-device compatibility.

## Technologies

- HTML5 — semantic structure and content
- CSS3 — visual design, layout, and responsive styling
- JavaScript — interactive navigation and menu behavior
- SVG — scalable vector graphics and custom branding
- Git and GitHub — version control and project hosting

## Development

The project involved translating the needs and identity of a real business into a functional website, from organizing content and defining the visual direction to implementing the interface and refining its behavior across devices.

Particular attention was given to making the menu easy to navigate, keeping the design consistent, and ensuring that essential information remains accessible on mobile.
